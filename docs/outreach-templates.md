# Outreach templates — RateShips link building

These are working templates for resource-page link building. Personalize each one before sending — never send raw template. Keep send rate to ~20-30 per day per inbox to avoid spam filters.

---

## How to find candidates (search operators)

Run these in Google. Each returns ~50-200 results to qualify:

```
"shipping calculator" inurl:resources
"international shipping" intitle:tools
"logistics resources" -inurl:rateships.com
"customs calculator" "useful tools"
"e-commerce resources" "shipping"
"freelance" "shipping tools"
"dropshipping" inurl:resources
"import duty" inurl:guide
"shipping guide" "tools we use"
```

For each result, qualify:
- DR (Ahrefs / Moz DA) ≥ 25 → worth pitching
- Page lists actual tools (not just spam)
- Page updated in last 24 months (last-modified or visible date)
- Author email findable (Hunter.io, manual check, or contact form)

## Template 1 — Generic resource page outreach (use 70% of time)

**Subject**: `Free shipping calculator for your {topic} resources page`

```
Hi {first_name},

Came across your {page_title} (link) — really useful list, especially the {specific_tool_already_listed} entry.

I run RateShips — a free shipping cost + customs duty calculator. No signup, supports 213 countries and 145 carriers, with VAT/de-minimis data sourced directly from each country's customs authority.

If it fits your list, here's a short description you could use:

> RateShips — Compare 145+ international carriers in 5 seconds. Built-in customs duty + VAT calculator for 213 countries. No signup, no email.
> https://rateships.com

Either way, thanks for putting that resource together — it's been useful to me too.

Best,
{your_name}
```

**Why it works:**
- Names a specific entry on their page → proves you read it
- Provides ready-to-paste copy + URL → reduces friction to ~10 seconds work
- Unsubscribe-friendly tone → "either way, thanks"
- No second-ask, no "let me know"

## Template 3 — Broken link building

Use Ahrefs / Screaming Frog to find dead 404 outbound links from logistics/ecommerce pages. Pitch yourself as replacement:

**Subject**: `Heads up — broken link on your {page_title}`

```
Hi {first_name},

Quick heads up — your page {page_url} has a broken link in the "{section_name}" section:

  {broken_link_url} → returns 404 (was a shipping calculator, looks like the project shut down)

Not sure if you're still maintaining the page, but if you replace it, we run a similar free tool: https://rateships.com (covers 213 countries, no signup).

Either way, thought you'd want to know.

— {your_name}
```

**Why it works:**
- You're doing them a favor first (broken link = bad UX, hurts their SEO)
- Replacement suggestion is implicit, not begging
- Conversion rate ~30-40% if the broken link is real and relevant

## Follow-up template (only ONCE, after 7 days, only if no reply)

**Subject**: `Re: {original_subject}` (literal "Re:")

```
Hi {first_name},

Just bumping this in case it got buried — totally fine if it's not a fit. Sent the original at {date} about including RateShips on your {page_title}.

Unsubscribing me from your follow-up list is easy: just don't reply.

Cheers,
{your_name}
```

**Stop after one follow-up.** Three is spam. Two with no reply means no — move on.

## Tracking spreadsheet

Track every send in a Google Sheet:

| Date | Site | Email | Template | Page | DR | Status | Notes |
|---|---|---|---|---|---|---|---|

Status options: `sent` / `bounced` / `replied-positive` / `replied-no` / `linked` / `ghosted`

Goal metric: **link conversion rate**. Healthy = 8-15%. Less than 5% = templates need work.

## Don'ts

- Never send the same template to two people at the same domain (gets flagged)
- Never use "Dear Sir/Madam" — instant delete
- Never pitch link in P1 — bury the ask in P2-P3
- Never claim "we're better than X" — sounds like aggressive SEO outreach
- Never offer link exchange — explicit Google guidelines violation
- Never offer money for a link — same, plus dishonest
- Never send from a generic "outreach@" address — use real founder email if possible

## Do's

- Mention something specific about THEIR content (proves you read)
- Include the ready-to-paste blurb so they don't have to think
- Set up SPF/DKIM/DMARC on your sending domain — without it, half land in spam
- Warm up new sending email for 2 weeks before bulk outreach (10 → 50 → 100 per day)
- Use your real first name (not "Editorial Team")
