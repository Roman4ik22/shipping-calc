# Track B — Publish `@rateships/customs` to npm

The package scaffold is in `docs/oss-package/`. I just rebuilt the `data/customs.json` file (213 countries, 51.5 KB). Everything else (src/, README, LICENSE, package.json) was already prepped.

**Steps for you to run:**

```bash
cd ~/Downloads/shipping-calc-repo/docs/oss-package

# 1. Install dependencies (first time only)
npm install

# 2. Run the test suite (sanity check)
npm test

# 3. Build dist/ (compiles TypeScript)
npm run build

# 4. Login to npm (one-time per machine)
npm login
# you'll be prompted for username, password, 2FA code

# 5. Verify the package contents that will be published
npm pack --dry-run

# 6. Publish to npm (public, scoped)
npm publish --access=public
```

**What you get:**
- `@rateships/customs` listed at https://www.npmjs.com/package/@rateships/customs (DR 95 backlink to rateships.com via the homepage URL in package.json)
- Auto-mirrored to:
  - `libraries.io` (DR 75) within ~24h
  - `repos.dev` (DR ~50)
  - `bundlephobia.com` (DR 81) when somebody benchmarks bundle size
  - `snyk.io/advisor/npm-package/...` (DR 89) within a week
  - `socket.dev` (DR 70) within ~24h

Each of these is one more dofollow backlink. **Total expected: 5-6 backlinks, DR 50-95.**

**What if `npm publish` fails?**

| Error | Fix |
|---|---|
| `404 — scope @rateships not found` | Need to create npm org first: https://www.npmjs.com/org/create — name "rateships", free tier. Then re-run publish. |
| `403 — package name already taken` | Someone else grabbed `@rateships/customs`. Try `@rateships-com/customs` or `rateships-customs` (unscoped). I can update package.json. |
| `EAUTH` | Re-run `npm login`. |

**After publish, also:**
1. Push the `docs/oss-package/` contents to a real GitHub repo at `https://github.com/rateships/customs` (creates a second backlink path: GitHub → npm → rateships.com)
2. Add `https://github.com/rateships/customs` topics: `shipping`, `customs`, `logistics`, `international`, `vat`, `nodejs`, `typescript`
3. Submit the npm URL to:
   - `https://github.com/RunaCapital/awesome-oss-alternatives` (PR, position as alt to Easyship/Shippo SDK)
   - `https://github.com/sindresorhus/awesome-nodejs` (PR after 30 days + 20 stars)
